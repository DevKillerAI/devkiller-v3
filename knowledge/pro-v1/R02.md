# React Pro Tailwind accessible local UI components and visual composition

Supported only in react-v4. Checked 2026-09-16. Tailwind 4.3.3 with Vite plugin already configured. clsx, tailwind-merge and class-variance-authority installed. Radix primitives are available via radix-ui. shadcn is a source-component approach, not an importable shadcn package. No pre-existing @/components aliases. Deliver complete local components and relative imports.

Sources: https://tailwindcss.com/docs/installation/using-vite and https://ui.shadcn.com/docs/installation/vite

Begin src/styles.css with @import "tailwindcss"; then add your theme CSS. Use complete literal class names, not constructed fragments like bg-${color}-500. Set root/body tokens so portals inherit them. Generated CSS is bundled locally; no CDN or runtime install. Use CSS custom properties or inline style for truly dynamic values.

Example src/components/ui/Button.jsx:
```jsx
import {clsx} from 'clsx';
import {twMerge} from 'tailwind-merge';
export function Button({className,type='button',...props}){
 return <button type={type} className={twMerge(clsx('inline-flex min-h-11 items-center justify-center gap-2 rounded-xl bg-orange-600 px-5 py-3 font-semibold text-white hover:bg-orange-700 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-orange-600 disabled:pointer-events-none disabled:opacity-50',className))} {...props}/>;
}
```
Example src/components/ui/Modal.jsx:
```jsx
import {Dialog} from 'radix-ui';
export function Modal({open,onOpenChange,title,description,children}){
 return <Dialog.Root open={open} onOpenChange={onOpenChange}><Dialog.Portal>
 <Dialog.Overlay className="fixed inset-0 z-40 bg-black/50"/>
 <Dialog.Content className="fixed left-1/2 top-1/2 z-50 max-h-[90dvh] w-[calc(100%-2rem)] max-w-lg -translate-x-1/2 -translate-y-1/2 overflow-auto rounded-2xl bg-white p-6 text-zinc-950 shadow-xl">
 <Dialog.Title className="text-xl font-bold">{title}</Dialog.Title>
 <Dialog.Description className="my-3 text-zinc-600">{description}</Dialog.Description>
 {children}<Dialog.Close className="mt-4 rounded-lg border px-4 py-3 focus-visible:outline-2">Close</Dialog.Close>
 </Dialog.Content></Dialog.Portal></Dialog.Root>;
}
```
If opened programmatically, explicitly restore focus to the opening control after closing. When using Dialog.Trigger, use asChild around one real button. Never nest buttons.

These examples establish behavior, not a mandatory orange visual identity. Choose typography, spacing, page structure and palette for the requested domain. Full application screens need loading/error/empty states and coherent photography, not repeated decorative cards. Responsive layout and accessibility remain necessary regardless of component libraries.
