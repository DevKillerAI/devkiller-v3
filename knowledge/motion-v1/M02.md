# Anime.js v4 motion components: SVG timelines, lifecycle and validation
Original DevKiller guidance, 2026-09-20. Installed animejs 4.5.0 on React, Next, Vue and Angular.
Use named imports {animate, createScope, createTimeline, svg} from 'animejs'. Do not generate the v3 default anime({targets}) API. Anime is useful for a deliberate sequence, diagrams and SVG line drawing; it is not product photography or a substitute for Recharts with real data.
Original minimal lifecycle recipe: inside the framework mount/effect, createScope({root: element}).add(() => { animate('.accent', {opacity:[0.65,1], duration:250, ease:'out(2)'}); }); retain the scope and call scope.revert() at unmount. Pass a real mounted root, not a document-wide selector. React uses useEffect/useRef; Vue uses onMounted/onUnmounted; Angular uses ngAfterViewInit and DestroyRef; Next requires a client boundary. A timeline created in the scope can coordinate elements but must be reverted with it. Keep content visible before enhancement. Respect matchMedia('(prefers-reduced-motion: reduce)') and skip decorative sequences; preserve final state and all business actions. Do not use animation completion to commit data. Avoid infinite loops, large blur filters and simultaneous transform ownership with Motion.
Test animation completion, remount without duplicate callbacks, route exit, keyboard/touch actions and reduced-motion behavior. For SVG use a valid viewBox and meaningful accessible labeling. Charts must represent saved records, not animated fabricated metrics.
