# Next App Router export and server boundaries
Engine next-v1 uses Next.js App Router static export. Deliver src/app/layout.jsx, src/app/page.jsx, src/styles.css and page folders. Interactive components need use client. No request-time Server Actions, cookies or Next API handlers in this profile. Separate Fastify APIs implement server behavior at /api. Static dynamic routes require generateStaticParams; unknown item IDs can use search params and client data fetching with Suspense. Do not read browser globals at build time. Do not fetch fonts during build. Use system fonts and unoptimized next/image. Data must not be hardcoded as a fake backend.
Sources: https://nextjs.org/docs/app/guides/static-exports ; https://nextjs.org/docs/app/getting-started/server-and-client-components
