# Vue and Angular native application modules
Vue: use SFC files, script setup, refs/computed, component props/emits and onUnmounted cleanup. Entry src/App.vue. Bootstrap is managed by Engine. Use lucide-vue-next or CSS, never React components. Angular: standalone AppComponent in src/app.component.ts, selector app-root, inline templates, signals and inject(). JIT with Vite; browser only. CommonModule must be explicitly imported when its directives are used. Both profiles use scoped source modules and async persisted data, with real error/loading/empty states. Optional Fastify backend follows the Engine backend contract.
Sources: https://vuejs.org/guide/quick-start.html ; https://angular.dev/guide/components
