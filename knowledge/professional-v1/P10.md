# P10 — Professional website and application composition, photography and delivery

Plan the audience, primary journey, screens and visual direction before generating files. A customer storefront and operator workspace have different composition. Use approved photos with recorded subject, role and crop; never relabel an unrelated object as a product. Match demo product data to actual available photos. Build shared theme tokens, readable type hierarchy, responsive grids, accessible dialogs and intentional empty/loading/error states. Separate domain calculations and persistence from UI components. Derive charts and totals from the same records. For inclusive rental dates use UTC calendar arithmetic, validate dates and quantity, and use peak concurrent reserved stock, not the sum of disjoint bookings. Keep write operations serialized and await persistence before confirmation. Compare rendered desktop and mobile screenshots to the design plan; a successful build alone is not a visual quality assessment. Prioritize functional completeness and distinctive domain-appropriate composition; avoid repeating cards and palettes. Record observed evidence, never claim unperformed browser tests.
