# S06 — Diverse premium graphics and app composition / identidade visual paletas ilustrações

Aplica-se a SVG/CSS em todas as stacks. Qualidade visual não exige o mesmo fundo, layout e desenho em todo projeto. Antes de compor, identificar tarefa principal, público, densidade de informação e linguagem de imagem. Uma ferramenta espacial deve priorizar canvas e inspector; uma agenda, tempo e compromissos; um laboratório, parâmetros e resultados; um site editorial, narrativa. Não adicionar hero de marketing a uma ferramenta de trabalho.

Choose a deliberate visual family: technical instrumentation, playful tactile workspace, clear professional tool, editorial gallery or calm high-density organizer. Then set background/surface/text/accent tokens, type scale, spacing, border and motion rules. Light, dark and mixed surfaces are options; beige is not a universal premium default. User-requested colors override the model's habitual palette.

Artwork needs semantic distinction. For a chair, draw a seat/back/legs; for a lamp, a shade/stem/base; for typography, letterform composition; for spatial design, distinct volumes. A function can share drawing helpers without sharing the same final silhouette. Palette variation alone is not eight different artworks. Build SVG in components with unique IDs, appropriate viewBox and deliberate stroke/shadow extents. Details must remain legible at actual display size.

Use chart forms to answer a question: trend line, comparison bars, distribution or proportions. Match tooltip/legend surfaces to theme, show units, use real filtered values and offer textual alternatives. Never use randomized chart data to make the dashboard look active. Animation must not distort the measurement.

For photographs and complex illustrations, this profile still lacks an integrated image-generation/upload pipeline. Use clearly intentional local graphic placeholders; never invent image URLs, random stock photos or promise photorealism. Future image assets need subject checks, source/usage metadata and budget control, not unlimited regeneration.

Review silhouette recognition, variety, contrast, cropping, semantics and interaction at both desktop and mobile sizes. Grade visual issues separately from functionality. Sources: user preferences and generated-app reviews dated 2026-09-14; https://www.w3.org/TR/SVG/coords.html . Author guidance, no claim of automatic aesthetic quality.
