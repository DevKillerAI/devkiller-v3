# S01 — React Studio stack: Radix, Motion, routes / bibliotecas e aplicativos com várias telas

Aplica-se somente a react-v3. React Studio mantém React 19.3.0, Vite 8.3.0, Lucide 1.45.0 e Recharts 3.10.1. Acrescenta radix-ui 1.6.7, motion 13.3.0 e react-router-dom 7.18.3. Não há instalação por pedido, backend arbitrário, imagens remotas ou autenticação embutida.

Allowed package imports: react, react/jsx-runtime, react/jsx-dev-runtime, lucide-react, recharts, radix-ui, motion/react, react-router-dom. Use exact names, not internal distribution paths. Files live in src/, including App.jsx export default and styles.css; platform supplies package.json, main.jsx and Vite configuration. Keep helpers and reusable components in separate local files as appropriate. An installed package is a capability, not an obligation to use it everywhere.

Escolha: Radix para diálogos, seletores e controles com teclado/foco; Motion para transições que expliquem mudanças; HashRouter para telas distintas; CSS/SVG para composição e desenhos; Recharts para dados quantitativos reais. Uma página simples pode usar apenas React/CSS. Não converter todos os aplicativos em sites com hero e cartões iguais.

The database is the platform HTTP API window.DevKillerDB. Read before editing, await writes, guard concurrent updates and preserve previous data after errors. Generated code must not assume filesystem paths, Windows, desktop software or localStorage. Deployment of the Engine online remains separate from the capabilities of this frontend profile.

Validate imports and build against the selected profile. A v3 source cannot be labeled v2; preserve saved projects' profile and dependencies during repair. Dependencies are pinned in compiler/studio/package-lock.json and exported with the project scaffold. Existing v1/v2 images remain separate.

Sources consulted 2026-09-14: local stack/compiler contract; https://www.radix-ui.com/primitives/docs/overview/getting-started ; https://motion.dev/docs/react-use-reduced-motion ; https://reactrouter.com/api/declarative-routers/HashRouter . Authored integration guidance.
