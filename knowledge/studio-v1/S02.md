# S02 — Accessible polished dialogs, menus, selectors and tabs / Radix foco teclado cores

react-v3 only. Radix supplies behavior, not visual styling. Design the open state with the same tokens as the rest of the app. Put theme variables on :root/body when portals are used, otherwise the portal may lose its theme. Opaque surface, readable text, border, radius, elevation, visible focus and adequate touch area are required.

Authored dialog skeleton:
```jsx
import {Dialog} from 'radix-ui';
<Dialog.Root>
  <Dialog.Trigger asChild><button type="button">Edit details</button></Dialog.Trigger>
  <Dialog.Portal>
    <Dialog.Overlay className="overlay"/>
    <Dialog.Content className="dialog">
      <Dialog.Title>Edit details</Dialog.Title>
      <Dialog.Description>Update this project's information.</Dialog.Description>
      <label>Name<input name="name"/></label>
      <Dialog.Close asChild><button type="button">Close</button></Dialog.Close>
    </Dialog.Content>
  </Dialog.Portal>
</Dialog.Root>
```
For persistent forms, control open/onOpenChange and close only after a successful awaited save. A failed save leaves the dialog open with a clear error. Never use Dialog.Close around Save if it would dismiss before the write succeeds. asChild requires one element that receives the supplied props/ref; a native button works. Never nest interactive buttons.

Radix modal handles focus and Escape; don't add competing global key handlers. Use Title and Description, meaningful labels and focus-visible CSS. A mobile drawer can style Dialog.Content at one side with width:min(90vw,24rem) and max-height:100dvh; only show its trigger on narrow screens. Keep desktop navigation as semantic nav and links.

Select anatomy: Select.Root value/onValueChange; Trigger containing Value and Icon; Portal containing Content, Viewport and Item value with ItemText and ItemIndicator. Use nonempty IDs, including "all". Style data-highlighted and data-state="checked" plus trigger disabled state. Size popover content to the available viewport and allow scrolling. DropdownMenu is for commands; use onSelect for actions. Tabs need Root, List, Trigger value and Content with matching value.

Font/color/background are not guaranteed by importing Radix. Do not copy a documentation demo that imports Tailwind or a different icon library. In v3 use local CSS and Lucide. Verify opening, keyboard selection, Escape, focus restoration, long labels, narrow viewports and reduced motion. Automated browser checks do not certify all assistive technologies.

Sources 2026-09-14: https://www.radix-ui.com/primitives/docs/components/dialog ; https://www.radix-ui.com/primitives/docs/guides/styling . Author synthesis and sample, not a copied theme.
