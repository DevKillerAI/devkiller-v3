# S03 — Motion animation, SVG depth and interactive canvas / animações suaves sem quebrar zoom

react-v3 only: import {motion, AnimatePresence, MotionConfig, useReducedMotion} from 'motion/react'. Use transitions to explain state changes, not to hide loading indefinitely. Configure reduced motion and keep all actions functional without animation.

```jsx
const reduce = useReducedMotion();
<motion.div initial={false} animate={{opacity:1,y:reduce?0:6}}
  transition={{duration:reduce?0:.18}}>Updated selection</motion.div>
```
For enter/exit, AnimatePresence must wrap the conditionally rendered keyed element. The node must remain mounted long enough to exit; don't place AnimatePresence inside the condition. Avoid animating layout for every pointer event or using random keys that reset the component. MotionConfig reducedMotion="user" helps set a consistent policy; explicitly disable repeating decorative effects when reduction is requested.

In editors, dragging coordinates belong to geometry, not animation state. Convert pointer coordinates to SVG space using the inverse screen CTM, or a correctly derived viewBox/rectangle transform. Account for zoom, padding, borders and pointer capture. Commit one undo entry at gesture completion. Don't let a motion transform overwrite the transform used for object rotation or zoom; animate a separate wrapper. Include numeric controls as an alternative to dragging.

Build visual depth from coherent silhouettes, distinct faces, gradients and shadows with unique IDs. A furniture library needs different shapes for chair, desk, lamp and plant. A category change is not merely a color change. On data charts, preserve legible axes and real values rather than emphasizing motion. Keep CSS and animation lightweight under the existing build/runtime limits.

Acceptance: state ends in the same result with reduced motion; keyboard can complete the task; zoom doesn't change object coordinates; no repeated writes for every frame. Source consulted 2026-09-14: https://motion.dev/docs/react-use-reduced-motion . Geometry recommendations are authored and require testing in the actual editor.
