# Q03 — Recharts analytics: responsive charts with real data and empty states

Scope: react-v3. Reference checked 2026-09-16: https://recharts.github.io/en-US/api/ResponsiveContainer/ . Original example using installed Recharts; container dimensions must be measurable.

File src/components/RevenueChart.jsx:
```jsx
import {ResponsiveContainer,BarChart,Bar,XAxis,YAxis,Tooltip} from 'recharts';
const dollars=n=>new Intl.NumberFormat('en-US',{style:'currency',currency:'USD',maximumFractionDigits:2}).format(n/100);
export default function RevenueChart({rows}) {
  if(!rows.length)return <section><h2>Booking value</h2><p>No bookings in this period.</p></section>;
  const total=rows.reduce((sum,row)=>sum+row.cents,0);
  return <section aria-label="Booking value by month"><h2>Booking value</h2><p>{dollars(total)} across {rows.length} months.</p><div style={{height:280,width:'100%',minWidth:0}}><ResponsiveContainer width="100%" height="100%"><BarChart data={rows}><XAxis dataKey="month"/><YAxis tickFormatter={dollars}/><Tooltip formatter={value=>[dollars(Number(value)),'Booking value']}/><Bar dataKey="cents" fill="var(--accent, #ed5b20)" radius={[4,4,0,0]}/></BarChart></ResponsiveContainer></div></section>;
}
```
Caller supplies sorted rows shaped {month:'2026-10',cents:8400}, derived from saved reservations, with an explicit cancellation/status inclusion policy. Never seed unrelated random chart values. Recompute when reservations or filters change. Keep prices as integer cents and convert only for display. A grid parent should use minmax(0,1fr) to prevent chart overflow. Empty data and zero-valued data are different states. Test totals against the reservation table and inspect mobile tooltips.
