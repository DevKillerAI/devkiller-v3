# Q07 — Playwright regression evidence: test errors are not app defects

Scope: all current Engine stacks. Source checked 2026-09-16: https://playwright.dev/docs/best-practices . Original synthesis and Engine-specific adaptation.

Test visible user behavior with isolated data. Prefer accessible roles or stable explicit test IDs over incidental DOM structure. Use retrying assertions for asynchronous UI state and avoid arbitrary sleeps as proof that saving completed. Each test creates its own prerequisites.

Engine DSL adaptation: text assertions compare the selected element's text, so target the message span rather than the entire toast including its close button. Do not expect one search result for a term appearing in several descriptions. Check that a selector exists in the delivered code before judging its failure. A reload test must reopen the relevant view if routing is not persistent. Cancellation and return are separate scenarios with separate active reservations.

Evidence records requirement, fixture, steps, expected/observed values, revision and source hash. A missing selector is inconclusive until checked against the requirement: it may be a wrong test or a missing feature. A timeout alone does not prove an application defect. Never repair working code merely to satisfy an invalid assertion. Preserve the prior preview while assessing a candidate. Proposed tests are not independently confirmed defects.
