# Q02 — Accessible Radix dialog and mobile navigation with complete CSS

Scope: react-v3, installed radix-ui umbrella package. Reference checked 2026-09-16: https://www.radix-ui.com/primitives/docs/components/dialog . Original minimal example; not copied upstream source. Radix supplies dialog interaction primitives; the application supplies styling, content and persistence.

Complete component, file src/components/DetailDialog.jsx:
```jsx
import { Dialog } from 'radix-ui';
import './detail-dialog.css';
export default function DetailDialog({title,description,children}) {
  return <Dialog.Root><Dialog.Trigger asChild><button type="button">View details</button></Dialog.Trigger><Dialog.Portal><Dialog.Overlay className="detail-overlay"/><Dialog.Content className="detail-panel"><Dialog.Title>{title}</Dialog.Title><Dialog.Description>{description}</Dialog.Description>{children}<Dialog.Close asChild><button type="button">Close details</button></Dialog.Close></Dialog.Content></Dialog.Portal></Dialog.Root>;
}
```
Complete stylesheet, file src/components/detail-dialog.css:
```css
.detail-overlay{position:fixed;inset:0;background:rgb(0 0 0 / .45);z-index:40}
.detail-panel{box-sizing:border-box;position:fixed;top:50%;left:50%;transform:translate(-50%,-50%);width:min(36rem,calc(100vw - 2rem));max-height:85dvh;overflow:auto;padding:1.5rem;background:var(--surface,#fff);color:var(--ink,#161616);border:1px solid var(--border,#aaa);border-radius:1rem;z-index:41}
.detail-panel button{font:inherit;cursor:pointer}
.detail-panel button:focus-visible{outline:3px solid var(--accent,#1746ed);outline-offset:3px}
```
For a mobile drawer, adapt the position and dimensions, retain title, description and close control. Close after route selection. Scope rail-only icon styles under the rail, never a global selector that hides drawer labels. Verify Tab, Escape, focus return, readable theme colors and 320px viewport. Do not substitute unavailable @radix-ui/react-dialog imports for the installed radix-ui package.
