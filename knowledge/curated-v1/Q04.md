# Q04 — Motion: purposeful animation and reduced-motion alternatives

Scope: react-v3. Reference checked 2026-09-16: https://motion.dev/docs/react-accessibility . Original synthesis. The installed package is motion: use imports from motion/react, not an uninstalled framer-motion dependency.

Use MotionConfig reducedMotion="user" at the animated application boundary. useReducedMotion supports custom choices such as replacing a large translating panel with a short opacity transition. Respect it for parallax, autoplay and decorative movement as well. Reduced motion should not hide content or remove functional feedback.

Engine design application: animate a dialog appearing, a selected tab marker or a completed save. Keep essential actions available immediately. Prefer brief transitions over staggered reveals across every card. Never make animation a substitute for actual progress or simulate a server response with a timer. Use stable keys for records, avoid remounting the entire page after edits, and preserve focus. A photograph remains a real asset, not an SVG animated approximation. Verify both motion settings in the browser and ensure layout remains usable without animation.
