# Q05 — Lucide icons, SVG and photography have different roles

Scope: react-v3. Source checked 2026-09-16: https://lucide.dev/guide/react . Original integration guidance for installed lucide-react.

Import named icons from lucide-react. Apply a coherent size and stroke weight. Give icon-only buttons accessible names and keep decorative icons hidden from assistive technology. An icon should clarify an action; it must not replace the product photograph or become an unexplained clickable square. Confirm the chosen export exists in the installed package.

For product catalogs, use Engine-approved photos with asset provenance. Write descriptions from visible subjects; a backpack attached to a mat does not establish waterproofing or capacity. Use object-fit:contain for isolated product views and deliberate cover crops for editorial scenes. Missing photography gets an explicit placeholder. Use authored SVG for diagrams and geometric branding, with a defined viewBox, legible labels and no external scripts. SVG is not a substitute for photography. Establish palette, geometry and visual purpose before drawing; avoid random overlapping shapes as a default hero.

Verify loaded image dimensions, mobile crop, attribution visibility, meaningful alt text and a graceful failed-image state. Do not claim a model-generated image depicts an actual product.
