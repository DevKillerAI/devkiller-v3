# D04 — Expressive hero art with local SVG / ilustração vetorial profundidade

Use for editorial landing pages, festivals, exhibitions and expressive product introductions. The illustration should communicate a theme and have a clear focal point, not merely fill the right-hand column with random thin shapes. Balance its visual weight against the headline. A complete composition can be built from a few deliberate primitives.

Choose a visual family to suit the subject: rhythmic wave paths for sound; bold cut-paper geometry for an exhibition; orbiting forms for technology; a typographic poster for a cultural event. These are choices, not a mandate for a dark neon site. Share the app palette through CSS variables. Prefer a strong silhouette, one main accent and supporting layers over many low-contrast effects.

Authored local SVG pattern for a dimensional ribbon (React):
```jsx
function RibbonArt(){
  const id=useId();
  return <svg viewBox="0 0 480 420" preserveAspectRatio="xMidYMid meet"
    aria-hidden="true" focusable="false" className="hero-art">
    <defs><linearGradient id={id} x1="0" y1="0" x2="1" y2="1" gradientUnits="objectBoundingBox">
      <stop stopColor="var(--accent)"/><stop offset="1" stopColor="var(--secondary)"/>
    </linearGradient></defs>
    <circle cx="240" cy="210" r="170" fill="none" stroke="currentColor" opacity=".18"/>
    <path d="M90 125 C330 20 385 160 170 220 C-5 280 250 390 375 290"
      fill="none" stroke="var(--shadow)" strokeWidth="70" transform="translate(0 16)"/>
    <path d="M90 125 C330 20 385 160 170 220 C-5 280 250 390 375 290"
      fill="none" stroke={`url(#${id})`} strokeWidth="58" strokeLinecap="round"/>
    <circle cx="375" cy="290" r="16" fill="var(--surface)"/>
  </svg>;
}
```
Import useId; IDs must be unique when multiple artworks occur on one page. Set width:100%, height:auto, display:block, pointer-events:none. Preserve viewBox proportions, leave room for stroke extents, and check cropping at narrow widths. Artwork should move below text on mobile when needed, not cover calls to action. A subtle transform animation is optional; stop it under prefers-reduced-motion. Do not animate expensive SVG filters continuously.

This illustration is decorative. Informative diagrams instead need an accessible name and textual explanation. SVG is real local code and does not require remote images, WebGL or new libraries. It can produce geometric artwork, not a guarantee of photorealistic illustration.
