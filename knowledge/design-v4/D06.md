# D06 — Data charts with visual depth and honest meaning / gráficos Recharts SVG

Use for finance, analytics, dashboards, progress and other real quantitative data. Decorative hero art is not a chart. Use a line for a trend, bars for comparisons, and avoid 3D distortions that obscure magnitudes. Start comparison bar axes at zero unless a different scale is essential and clearly explained.

In react-v2 Recharts is available. Give ResponsiveContainer a parent with a real minimum height and width; otherwise an empty chart may be a layout problem. Map semantic color tokens into series, axes, grid and tooltip surfaces. Tooltips in dark layouts need their own readable background and foreground. Keep units, currency and date labels explicit. Include a text summary or small accessible table, so hover and color are not the only ways to read values.

Use the same filtered records and selectors for totals, tables and charts. Unknown values are gaps or “To be defined”, not invented zeroes. Empty datasets get a designed empty state, not fabricated success metrics. If the request authorizes demo data, label it and keep it distinct from real saved records.

For a small custom SVG chart, define the coordinate space with viewBox, reserve label margins, derive positions from actual data and keep proportions responsive. Handle empty arrays and zero-range data explicitly; never divide by zero or emit NaN path coordinates. Gradients may add emphasis without replacing the readable outline of the data series.

Verification: change a filter and compare chart totals with the table; check empty/single-value/long-label datasets and a narrow viewport. A chart rendering successfully does not prove its arithmetic. Do not hide a failed chart behind arbitrary mock data.

Sources: local DevKiller react-v2 Recharts contract; https://www.w3.org/TR/SVG/coords.html (consulted 2026-09-14). Authored chart guidance; no new plotting dependency.
